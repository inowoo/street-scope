# STREET SCOPE v0.7

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街を見下ろすスナイパー視点で、指定された人物・車・看板・窓の人物を探して狙撃するカジュアルゲームです。

リアルな弾道シミュレーションより、以下の手触りを優先します。

- 通常時は照準カーソルだけを自由に動かす
- カメラはマウス中ボタンを押している間だけ動かす
- スコープ中はマウス移動とカメラを直接連動させる
- 発射した弾が飛んでいくのを見せる
- 着弾エフェクトと破壊演出を出す
- 道路の終端が見えない、広い街からターゲットを探す

風向き・重力・弾道落下などの複雑な計算は行いません。

## 技術仕様

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 入力: Pointer Lock API
- 命中判定: レイキャスト
- 弾丸表示: レイキャストとは別に短時間の弾丸・トレーサーを表示
- 表現: ローポリ、非グロ
- `index.html`: UI / HUD / エントリポイント
- `world.js`: 街・人物・車・背景・ターゲット配置
- `game.js`: カメラ・射撃・破壊演出・ミッション・入力

## 現在のゲームルール

画面上部の `CURRENT MISSION` に指定された対象を撃ちます。

例:

- 人物【赤】を撃て
- 車【青】を撃て
- 看板【黄】を撃て
- 窓の人物【白】を撃て

### 色覚への配慮

ミッション対象色は以下の5色のみです。

- 赤
- 青
- 黄
- 黒
- 白

色だけではなく、必ず `人物 / 車 / 看板 / 窓の人物` の種類名も併記します。

## カメラ / 照準

### 通常時

- マウス移動ではカメラを動かさず、クロスヘアだけを移動
- クロスヘアはほぼ画面全体を移動可能
- 画面端まで動かしてもカメラは自動追尾しない
- マウス中ボタンを押している間だけ、マウス移動とカメラ回転を直接同期
- 射撃判定は現在のクロスヘア位置から行う

### スコープ時

- 右クリック長押しでスコープ
- スコープ照準は中央固定
- マウス移動とカメラ回転を直接同期
- マウスホイールで2.0x〜8.0xズーム

## 射撃 / 着弾

- 左クリックで射撃
- レイキャストで命中判定
- 表示上の弾丸とトレーサーが着弾点へ飛ぶ
- 地面・道路・歩道・建物は壊れない
- 環境への命中時は火花・粉塵エフェクト
- ターゲットへの命中時は破片化して壊れる演出
- ターゲットは一定時間後に再出現

## 移動オブジェクト

### 車

- 複数レーンを走行
- 個体ごとに速度差あり
- 同じレーンの前方車両との距離を見て減速 / 停止
- v0.7ではレーンごとに初期位置と再出現境界をずらし、別レーン同士も同じ奥行きに揃いにくくした
- 最低車間距離を広げて重なりにくくした

### 歩行者

- 複数の歩道レーンを移動
- 同じレーンの前方歩行者との距離を見て減速 / 停止
- v0.7ではレーンごとに初期位置と再出現境界をずらした
- 最低間隔を広げて重なりにくくした

## 街

### v0.7の方針

「道路の先が見切れて終端が見える」状態を避けるため、ゲームプレイ範囲よりかなり大きい3D街を描画します。

- メイン道路をカメラの有効視距離より先まで延長
- 奥方向・手前方向に道路を約2km級まで継続
- 約140m間隔で複数の十字路を配置
- 十字路の左右にも長い道路を配置
- 交差道路の周囲にもビル群を配置
- プレイ範囲を越えた先にも簡略化したビル街を継続
- 左右のビルを複数列構成にする
- 一部の手前ビルには窓と窓内ターゲットを配置
- フォグで遠方を自然に背景へ馴染ませる

### 背景 / 書き割り

街の外側が見えにくいように、3D街とは別に遠景も配置します。

- プレイヤー周囲を大きく囲う円筒状の背景を追加
- 背景は空色系の簡易スカイドーム / 書き割りとして使用
- その手前に円形の遠景スカイラインを配置
- カメラを左右へ大きく振った場合も、街の外側の空白が出にくい構成

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 通常時: クロスヘア移動 / スコープ時: カメラ操作 |
| マウス中ボタン長押し + マウス移動 | 通常時のカメラ旋回 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

GitHub Pagesを有効にしている場合:

```text
https://inowoo.github.io/street-scope/
```

ローカルではリポジトリのルートで以下を実行します。

```bash
python -m http.server 8000
```

その後:

```text
http://localhost:8000/
```
