# STREET SCOPE

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろすスナイパー視点で、指定された人物・車・物体を探して狙撃するカジュアルなブラウザゲームです。

リアルな狙撃シミュレーターではなく、以下の手触りを優先します。

- スコープを覗く
- ズームしてターゲットを探す
- マウスで照準を合わせる
- 気持ちよく撃つ
- 正しい対象を素早く見つける

風向き、重力、弾道落下などの複雑な計算は行いません。

## 技術仕様

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 操作: マウス中心
- 入力: Pointer Lock API
- 弾道: 照準中央へのレイキャスト即着弾
- 風・重力・弾道落下: なし
- 表現: ローポリ、非グロ
- `index.html`: UI / HUD / エントリポイント
- `world.js`: 街・人物・車・ターゲット配置
- `game.js`: カメラ・射撃・ミッション・スコア・入力

## 現在のゲームルール

画面上部に `CURRENT MISSION` が表示されます。

例:

- 赤い服の人物を撃て
- 青い車を撃て
- 黄色い看板を撃て
- オレンジ色の箱を撃て

指定された対象を撃つとミッションクリアとなり、すぐ次のミッションが提示されます。

### 正解

- 基本得点: 180点
- 距離に応じたボーナスあり
- 連続正解によるストリークボーナスあり
- STREAKが1増える
- 次のミッションへ進む

### 誤射

- 50点減点
- STREAKが0に戻る
- 人物・車を誤射した場合、その対象は一時的に消えて再出現する

### タイムアップ

- 1ミッションの制限時間は22秒
- 時間切れで100点減点
- STREAKが0に戻る
- 次のミッションへ進む

## カメラ / 照準

- 一人称の固定狙撃位置から街路を見下ろす
- マウス移動で照準
- 通常時は画面中央にクロスヘア表示
- 右クリック長押し中はスコープ表示
- スコープ中はマウス感度を低下
- マウスホイールで2.0x〜8.0xのズーム

## 射撃

- 左クリックで射撃
- レイキャストによる即着弾
- 射撃間隔あり
- 小さなリコイルあり
- 正解時にヒットマーカー表示
- 命中位置に簡易エフェクト表示

## 弾薬 / リロード

- 1マガジン5発
- `R`キーでリロード
- リロード中は射撃不可
- 弾切れ時は自動リロード
- HUDに残弾数とリロード状態を表示

## ターゲット

### 歩行者

- ローポリの簡易ダミー表現
- 歩道を移動
- 服の色: 赤 / 青 / 緑 / 黄
- 命中すると一時的に消え、一定時間後に再出現
- 流血・グロ表現なし

### 車

- 道路を走行
- 車体色: 赤 / 青 / 緑 / 黄
- 命中すると一時的に消え、一定時間後に再出現

### 看板

- 静止ターゲット
- 色: 赤 / 青 / 黄

### 箱

- 静止ターゲット
- 一部のオレンジ色の箱がミッション対象

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 照準 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

リポジトリのルートで簡易HTTPサーバーを起動します。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

Babylon.jsをCDNから読み込むため、インターネット接続が必要です。
