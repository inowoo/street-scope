# STREET SCOPE

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろすスナイパー視点で、歩行者・車・箱・看板などを狙撃するシンプルなブラウザゲームです。
リアルな狙撃シミュレーターではなく、マウスで照準を合わせてスコープを覗き、ズームして撃つ気持ちよさを優先します。

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 操作: マウス中心
- 弾道: 照準中央への即着弾
- 風・重力・弾道落下: なし
- 表現: ローポリ、非グロ

## 現在の仕様

### カメラ / 照準

- 一人称の固定狙撃位置から街路を見下ろす
- マウス移動で照準
- Pointer Lock APIを使用
- 通常時は画面中央にクロスヘア表示
- 右クリック長押し中はスコープ表示
- スコープ中はマウス感度を低下
- マウスホイールで2.0x〜8.0xのズーム

### 射撃

- 左クリックで射撃
- レイキャストによる即着弾
- 射撃間隔あり
- 小さなリコイルあり
- 命中時にヒットマーカーと簡単な命中エフェクトを表示
- 距離と対象に応じてスコア加算

### 弾薬 / リロード

- 1マガジン5発
- `R`キーでリロード
- リロード中は射撃不可
- 弾切れ時は自動的にリロード開始
- HUDに残弾数とリロード状態を表示

### 街

- 道路
- センターライン
- 歩道
- 建物
- 窓
- 街灯
- 屋上の手すり
- 距離フォグ

### ターゲット

- 歩行者
  - ローポリの簡易ダミー表現
  - 歩道を移動
  - 命中すると一時的に消え、一定時間後に再出現
- 車
  - 道路を走行
  - 命中すると一時的に消え、一定時間後に再出現
- 箱
  - 静止ターゲット
- 看板
  - 静止ターゲット

### HUD

- SCORE
- HIT
- AMMO
- READY / RELOADING
- クロスヘア
- スコープレティクル
- 現在のズーム倍率
- ヒットマーカー
- 命中時の加点表示
- リロードバー

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 照準 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

`index.html` をブラウザで開きます。
Babylon.jsをCDNから読み込むため、インターネット接続が必要です。

ローカルファイルでの実行に制限がある場合は、リポジトリのルートで簡易HTTPサーバーを起動します。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

## ゲーム性について

現段階は「狙う・ズームする・撃つ」の基本操作確認を目的にしたプロトタイプです。
今後は、単純なフリー射撃だけではなく、短時間で理解できるカジュアルなミッションを追加する想定です。

候補:

- 指定された色の人物だけを狙う
- 特定の車を探して撃つ
- 一般ターゲットを撃つと減点
- 制限時間内に複数の看板を撃つ
- コンボ / 連続命中
- 距離ボーナス
- スコープ倍率に応じた得点補正
