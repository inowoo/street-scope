# STREET SCOPE v0.8

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろし、指定された人物・車・看板・窓の人物を探して撃つカジュアル3Dスナイパーです。

リアルな弾道計算より、探す・狙う・撃つ気持ちよさを優先します。

- 通常時はクロスヘアだけを自由に動かす
- 中ボタンを押している間だけカメラを旋回
- スコープ中はマウス移動とカメラを直接連動
- 弾丸とトレーサーを表示
- 着弾エフェクトと破壊演出
- 広い街からターゲットを探す
- たまに空を横切るボーナス航空機を狙う

風・重力・弾道落下はありません。

## 操作

| 操作 | 内容 |
|---|---|
| マウス移動 | 通常時: 黄色クロスヘアを移動 / スコープ時: カメラ操作 |
| 中ボタン長押し + マウス移動 | 通常時のカメラ旋回 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | 2x〜8xズーム |
| R | リロード |
| Esc | マウスロック解除 |

## ミッション

`CURRENT MISSION` に指定された対象を撃ちます。

例:

- 人物【赤】
- 車【青】
- 看板【黄】
- 窓の人物【白】

色は赤 / 青 / 黄 / 黒 / 白の5色だけを使用します。

### 正解

- 基本得点: 180点
- 距離ボーナスあり
- STREAKボーナスあり
- ターゲットは破片化して消える

### 誤射

- 50点減点
- STREAKリセット

### タイムアップ

- 1ミッション22秒
- 100点減点
- STREAKリセット

## ボーナス航空機

v0.8から、一定間隔で飛行機またはヘリコプターが空を横切ります。

- 飛行機: +700点
- ヘリコプター: +900点
- ミッション対象とは別枠
- 撃っても通常ミッションのSTREAKは失わない
- 命中すると破片化して消える

## カメラ / クロスヘア

### 通常時

- クロスヘアは黄色
- マウス移動ではカメラは動かない
- クロスヘアは画面内を自由に移動
- 画面端に行ってもカメラ自動追尾はしない
- 中ボタンを押している間だけ、マウス移動でカメラ旋回
- 射撃判定は現在のクロスヘア位置

### スコープ時

- 右クリック長押し
- 中央固定レティクル
- マウスとカメラを直接連動
- ホイールで2x〜8x

## 街

v0.8では道路の終端表現を修正しました。

- メイン道路は遠方で突然ビルに突き当たらない
- 道路の両端は正式なT字路として構成
- T字路の左右に道路が続く
- T字路の向こう側は市街地ブロック
- 途中にも複数の十字路
- 左右方向にも道路と建物を配置
- メイン道路沿いは複数列のビル
- 遠景スカイラインあり
- 空は明るいプロシージャル・スカイボックス
- 一部の窓に人物ターゲット

### 車 / 歩行者の重なり防止

- 初期スポーン時に同種オブジェクトのZ位置をずらす
- 同じレーンだけでなく、別レーンでも同じ奥行きに密集しすぎないよう間隔を確保
- 再出現時も同レーン距離と同種全体の奥行き距離をチェック
- 前方オブジェクトに近づいた場合は減速 / 停止

## 射撃 / 破壊

- レイキャストで即時命中判定
- 表示用の弾丸とトレーサーが着弾点まで飛ぶ
- 地面 / 道路 / 建物は壊れない
- 環境への着弾は火花・粉塵エフェクト
- 人物 / 車 / 看板 / 窓の人物 / ボーナス航空機は破片化
- 縮小して消える演出は使用しない

## 技術

- Babylon.js（CDN）
- Pointer Lock API
- `index.html`: UI / HUD
- `world.js`: 街・道路・建物・ターゲット配置・スカイボックス
- `game.js`: 入力・カメラ・射撃・ミッション・破壊・ボーナス航空機
