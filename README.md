# STREET SCOPE

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろすスナイパー視点で、指定された人物・車・看板を探して狙撃するカジュアルなブラウザゲームです。

リアルな狙撃シミュレーターではなく、以下の手触りを優先します。

- 通常時は照準カーソルを画面中央付近で自由に動かす
- 通常時、照準が一定範囲を越えた分だけカメラが追従する
- スコープ中はマウス移動とカメラをほぼ直接同期させる
- 発射した弾丸がターゲット方向へ飛んでいくのが見える
- 着弾時にエフェクトが出る
- ターゲットは被弾後に破壊演出を経て消える
- 正しい対象を素早く見つける

風向き、重力、弾道落下などの複雑な計算は行いません。

## 技術仕様

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 操作: マウス中心
- 入力: Pointer Lock API
- 命中判定: レイキャストによる即時判定
- 弾丸表示: レイキャストとは別に短時間の弾丸・トレーサーを表示
- 着弾演出: 弾丸表示が着弾点へ到達したタイミングで再生
- 風・重力・弾道落下: なし
- 表現: ローポリ、非グロ
- `index.html`: UI / HUD / エントリポイント
- `world.js`: 街・人物・車・ターゲット配置
- `game.js`: カメラ・射撃・破壊演出・ミッション・スコア・入力

## 現在のゲームルール

画面上部に `CURRENT MISSION` が表示されます。

例:

- 人物【赤】を撃て
- 車【青】を撃て
- 看板【黄】を撃て
- 人物【黒】を撃て
- 車【白】を撃て

指定された対象を撃つとミッションクリアとなり、次のミッションが提示されます。

### 色覚への配慮

ミッション対象に使用する色は以下の5色です。

- 赤
- 青
- 黄
- 黒
- 白

緑・オレンジなどの判別しづらい中間色はミッション指定に使用しません。

色だけでなく必ず `人物 / 車 / 看板` の種類を同時に指定します。
ターゲット本体には輪郭線を付けています。

### 正解

- 基本得点: 180点
- 距離ボーナスあり
- 連続正解によるストリークボーナスあり
- STREAKが1増える
- ターゲットは破壊演出後に一時的に消える
- 次のミッションへ進む

### 誤射

- 50点減点
- STREAKが0に戻る
- 誤射したターゲットも破壊演出後に一時的に消える

### タイムアップ

- 1ミッションの制限時間は22秒
- 時間切れで100点減点
- STREAKが0に戻る
- 次のミッションへ進む

## カメラ / 照準

### 通常時

- 一人称の固定狙撃位置から街路を見下ろす
- 画面中央を中心とした円形のフリーエイム範囲を持つ
- マウスを動かしても、まずはカメラを動かさずクロスヘアだけが移動する
- クロスヘアがフリーエイム範囲の端を越えようとした分だけカメラが追従する
- 射撃判定は現在のクロスヘア位置から行う
- フリーエイム範囲は画面サイズに応じて変化する

### スコープ時

- 右クリック長押しでスコープ表示
- マウス移動とカメラ回転をほぼ直接同期する
- スコープ照準は画面中央固定
- ズーム倍率に応じてカメラ感度を補正する
- マウスホイールで2.0x〜8.0xのズーム
- 射撃判定はスコープ中央から行う

## 射撃

- 左クリックで射撃
- 命中判定自体はレイキャストによる即時判定
- 発射時に弾丸と短いトレーサーを生成
- 弾丸表示が着弾点まで飛んだ後に着弾演出を再生
- 射撃間隔あり
- 小さなリコイルあり

### 地面 / 建物への着弾

- 地面・道路・歩道・建物などは破壊しない
- 着弾点に火花 / 粉塵風の簡易エフェクトを表示
- 地面自体の形状は変化しない

### ターゲットへの着弾

- 命中点にフラッシュと破片エフェクトを表示
- 人物 / 車は縮小・傾きの簡易破壊演出を行ってから消える
- 看板などの静止ターゲットも縮小・回転して消える
- 消えたターゲットはゲーム継続用に一定時間後に再出現する
- 流血・グロ表現なし

## 弾薬 / リロード

- 1マガジン5発
- `R`キーでリロード
- リロード中は射撃不可
- 弾切れ時は自動リロード
- HUDに残弾数とリロード状態を表示

## ターゲット

### 歩行者

- ローポリの簡易ダミー表現
- 歩道を移動
- 服の色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 被弾時に破壊演出
- 一定時間後に再出現
- 流血・グロ表現なし

### 車

- 道路を走行
- 車体色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 被弾時に破壊演出
- 一定時間後に再出現

### 看板

- 静止ターゲット
- 色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 被弾時に破壊演出
- 一定時間後に再出現

### 箱

- 静止オブジェクト
- 現在はミッション対象外
- 命中時は破壊対象として扱う場合がある

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 通常時: フリー照準 + 端でカメラ追従 / スコープ時: カメラ直接操作 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

リポジトリのルートで簡易HTTPサーバーを起動します。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

Babylon.jsをCDNから読み込むため、インターネット接続が必要です。

GitHub Pagesを有効にしている場合は、以下から直接プレイできます。

```text
https://inowoo.github.io/street-scope/
```
