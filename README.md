# STREET SCOPE

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろすスナイパー視点で、指定された人物・車・看板・窓の人物を探して狙撃するカジュアルなブラウザゲームです。

リアルな狙撃シミュレーターではなく、以下の手触りを優先します。

- 通常時はできるだけカメラを動かさず、クロスヘアだけを動かす
- 必要なときだけ中ボタンを押してカメラを旋回する
- スコープ中はマウス移動とカメラを直接同期する
- 弾丸がターゲット方向へ飛んでいくのが見える
- 着弾時にエフェクトが出る
- ターゲットは破片化して壊れ、消える
- 広めの街からターゲットを探す

風向き、重力、弾道落下などの複雑な計算は行いません。

## 技術仕様

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 操作: マウス中心
- 入力: Pointer Lock API
- 命中判定: レイキャストによる即時判定
- 弾丸表示: レイキャストとは別に短時間の弾丸・トレーサーを表示
- 着弾演出: 弾丸表示が着弾点へ到達したタイミングで再生
- 風・重力・弾道落下: なし
- 表現: ローポリ、非グロ
- `index.html`: UI / HUD / エントリポイント
- `world.js`: 街・人物・車・窓ターゲット・配置
- `game.js`: カメラ・射撃・破壊演出・ミッション・スコア・入力・移動制御

## 現在のゲームルール

画面上部に `CURRENT MISSION` が表示されます。

例:

- 人物【赤】を撃て
- 車【青】を撃て
- 看板【黄】を撃て
- 窓の人物【黒】を撃て
- 窓の人物【白】を撃て

指定された対象を撃つとミッションクリアとなり、次のミッションが提示されます。

### 色覚への配慮

ミッション対象に使用する色は以下の5色です。

- 赤
- 青
- 黄
- 黒
- 白

色だけでなく、必ず `人物 / 車 / 看板 / 窓の人物` の種類も同時に指定します。
ターゲット本体には輪郭線を付けています。

### 正解

- 基本得点: 180点
- 距離ボーナスあり
- 連続正解によるストリークボーナスあり
- STREAKが1増える
- ターゲットは破片化して消える
- 次のミッションへ進む

### 誤射

- 50点減点
- STREAKが0に戻る
- 誤射したターゲットも破壊される

### タイムアップ

- 1ミッションの制限時間は22秒
- 時間切れで100点減点
- STREAKが0に戻る
- 次のミッションへ進む

## カメラ / 照準

### 通常時

- マウス移動ではカメラを動かさず、クロスヘアだけを動かす
- クロスヘアは画面中央を中心とした広めの円形範囲内を移動する
- 円の端まで到達しても自動ではカメラを動かさない
- カメラを旋回したいときはマウス中ボタンを押しながらマウスを動かす
- 中ボタン操作中もクロスヘア位置は保持する
- 射撃判定は現在のクロスヘア位置から行う

### スコープ時

- 右クリック長押しでスコープ表示
- マウス移動とカメラ回転をほぼ直接同期する
- スコープ照準は画面中央固定
- ズーム倍率に応じてカメラ感度を補正する
- マウスホイールで2.0x〜8.0xのズーム
- 射撃判定はスコープ中央から行う

## 射撃 / 着弾

- 左クリックで射撃
- 命中判定はレイキャストによる即時判定
- 表示上は弾丸とトレーサーが着弾点まで飛ぶ
- 弾丸が到達したタイミングで着弾・破壊演出を再生
- 地面・道路・歩道・建物は壊れない
- 環境への着弾時は火花 / 粉塵風エフェクトのみ表示

## 破壊演出

従来の「スケールを小さくして消す」方式は廃止しました。

- 人物: 本体を即座に非表示にし、複数の破片を飛散させる
- 車: 人物より多めの破片を飛散させる
- 看板: 看板とポールをまとめて破片化する
- 窓の人物: 窓内の人物を破片化して消す
- 破片は回転しながら落下し、一定時間後に消える
- ゲーム継続のため、ターゲット自体は数秒後に再出現する
- 流血・グロ表現なし

## 街

v0.5で街の表示範囲を拡張しました。

- 道路の全長を拡大
- 道幅を拡大し、複数車線化
- 交差道路を追加
- 左右のビル数を増加
- ビルを高層化・遠景まで配置
- 描画距離を拡大
- 距離フォグの開始・終了距離を遠くへ変更
- 街灯、歩道、看板、箱などを広い範囲へ再配置

## 移動オブジェクトの重なり防止

車と歩行者には物理コリジョンは使用していません。

代わりに、同じ移動レーン内の前方オブジェクトとの距離を毎フレーム確認し、近づいた場合に速度を落とします。

- 車: 4レーンに分離
- 歩行者: 左右歩道を進行方向別の4レーンに分離
- 同じレーン内で前方との距離が短い場合は減速または停止
- 元の個体ごとの速度差は維持しつつ、追いついた際に重ならないよう調整

## ターゲット

### 歩行者

- 歩道を移動
- 服の色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 被弾時に破片化
- 一定時間後に再出現

### 車

- 複数車線を走行
- 車体色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 被弾時に破片化
- 一定時間後に再出現

### 看板

- 静止ターゲット
- 色: 赤 / 青 / 黄 / 黒 / 白
- 看板とポールをまとめて破壊
- 一定時間後に再出現

### 窓の人物

- 一部のビル窓に配置
- 上半身が窓越しに見える簡易表現
- 服の色: 赤 / 青 / 黄 / 黒 / 白
- `窓の人物` として独立したミッション対象
- 被弾時に破片化して消える
- 一定時間後に再出現

### 箱

- 静止オブジェクト
- 現在はミッション対象外

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 通常時: クロスヘアのみ移動 / スコープ時: カメラ直接操作 |
| マウス中ボタン長押し + マウス移動 | 通常時のカメラ旋回 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

ローカルではリポジトリのルートで以下を実行します。

```bash
python -m http.server 8000
```

その後:

```text
http://localhost:8000/
```

GitHub Pages:

```text
https://inowoo.github.io/street-scope/
```
