# STREET SCOPE

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろすスナイパー視点で、指定された人物・車・物体を探して狙撃するカジュアルなブラウザゲームです。

リアルな狙撃シミュレーターではなく、以下の手触りを優先します。

- スコープを覗く
- ズームしてターゲットを探す
- スコープ内で照準を細かく動かす
- スコープ端まで照準を動かすとカメラが追従する
- 発射した弾がターゲット方向へ飛んでいくのが見える
- 正しい対象を素早く見つける

風向き、重力、弾道落下などの複雑な計算は行いません。

## 技術仕様

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 操作: マウス中心
- 入力: Pointer Lock API
- 命中判定: レイキャストによる即時判定
- 弾丸表示: 命中判定とは別に短時間のトレーサー表示
- 風・重力・弾道落下: なし
- 表現: ローポリ、非グロ
- `index.html`: UI / HUD / エントリポイント
- `world.js`: 街・人物・車・ターゲット配置
- `game.js`: カメラ・射撃・ミッション・スコア・入力

## 現在のゲームルール

画面上部に `CURRENT MISSION` が表示されます。

例:

- 人物【赤】を撃て
- 車【青】を撃て
- 看板【黄】を撃て
- 人物【黒】を撃て
- 車【白】を撃て

指定された対象を撃つとミッションクリアとなり、すぐ次のミッションが提示されます。

### 色覚への配慮

ミッション対象に使用する色は、現状以下の5色だけです。

- 赤
- 青
- 黄
- 黒
- 白

緑・オレンジなどの判別しづらい中間色はミッション指定に使用しません。

また、色だけでなく必ず `人物 / 車 / 看板` の種類を同時に指定します。
ターゲット本体には輪郭線を付け、背景との境界も見やすくしています。

### 正解

- 基本得点: 180点
- 距離に応じたボーナスあり
- 連続正解によるストリークボーナスあり
- STREAKが1増える
- 次のミッションへ進む

### 誤射

- 50点減点
- STREAKが0に戻る
- 人物・車を誤射した場合、その対象は一時的に消えて再出現する

### タイムアップ

- 1ミッションの制限時間は22秒
- 時間切れで100点減点
- STREAKが0に戻る
- 次のミッションへ進む

## カメラ / 照準

### 通常時

- 一人称の固定狙撃位置から街路を見下ろす
- マウス移動でカメラと照準が直接連動
- 画面中央にクロスヘア表示

### スコープ時

- 右クリック長押しでスコープ表示
- マウスホイールで2.0x〜8.0xのズーム
- スコープ円の内側では、カメラを動かさず照準カーソルだけが移動する
- 照準カーソルは円形範囲内に制限される
- 照準を円の端まで動かし、さらにマウスを動かすとカメラがその方向へ追従する
- 円の端からマウスを戻すと、まず照準カーソルが円内へ戻る
- 射撃判定は画面中央ではなく、現在のスコープ照準位置から行う

この方式をスコープ時の「フリーエイム」として扱います。

## 射撃

- 左クリックで射撃
- 命中判定自体はレイキャストによる即時判定
- 発射時に弾丸と短いトレーサーを生成し、狙った位置まで短時間で飛ばす
- 射撃間隔あり
- 小さなリコイルあり
- 正解時にヒットマーカー表示
- 命中位置に簡易エフェクト表示
- 建物や地面など、途中のオブジェクトに当たった場合はそこで弾丸表示を止める

## 弾薬 / リロード

- 1マガジン5発
- `R`キーでリロード
- リロード中は射撃不可
- 弾切れ時は自動リロード
- HUDに残弾数とリロード状態を表示

## ターゲット

### 歩行者

- ローポリの簡易ダミー表現
- 歩道を移動
- 服の色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 命中すると一時的に消え、一定時間後に再出現
- 流血・グロ表現なし

### 車

- 道路を走行
- 車体色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり
- 命中すると一時的に消え、一定時間後に再出現

### 看板

- 静止ターゲット
- 色: 赤 / 青 / 黄 / 黒 / 白
- ターゲット輪郭あり

### 箱

- 静止オブジェクト
- 現在はミッション対象外

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 通常時: カメラ照準 / スコープ時: フリー照準 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

リポジトリのルートで簡易HTTPサーバーを起動します。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

Babylon.jsをCDNから読み込むため、インターネット接続が必要です。

GitHub Pagesを有効にしている場合は、以下から直接プレイできます。

```text
https://inowoo.github.io/street-scope/
```
