# STREET SCOPE v0.6

ブラウザで動く3Dスナイパーゲームのプロトタイプです。

## コンセプト

街路を見下ろすスナイパー視点で、指定された人物・車・看板・窓の人物を探して狙撃するカジュアルゲームです。

リアルな弾道シミュレーションより、以下の手触りを優先します。

- 通常時は照準カーソルだけを自由に動かす
- カメラはマウス中ボタンを押している間だけ動かす
- スコープ中はマウス移動とカメラを直接連動させる
- 発射した弾が飛んでいくのを見せる
- 着弾エフェクトと破壊演出を出す
- 指定された対象を素早く見つける

風向き・重力・弾道落下などの複雑な計算は行いません。

## 技術仕様

- 対応環境: デスクトップWebブラウザ
- 3Dエンジン: Babylon.js（CDN）
- 入力: Pointer Lock API
- 命中判定: レイキャスト
- 弾丸表示: レイキャストとは別に短時間の弾丸・トレーサーを表示
- 表現: ローポリ、非グロ
- `index.html`: UI / HUD / エントリポイント
- `world.js`: 街・人物・車・ターゲット配置
- `game.js`: カメラ・射撃・破壊演出・ミッション・入力

## 現在のゲームルール

画面上部の `CURRENT MISSION` に指定された対象を撃ちます。

例:

- 人物【赤】を撃て
- 車【青】を撃て
- 看板【黄】を撃て
- 窓の人物【白】を撃て

### 色覚への配慮

ミッション対象色は以下の5色のみです。

- 赤
- 青
- 黄
- 黒
- 白

色だけではなく、必ず `人物 / 車 / 看板 / 窓の人物` の種類名も併記します。

## カメラ / 照準

### 通常時

- マウス移動ではカメラを動かさず、クロスヘアだけを移動
- クロスヘアは円形範囲ではなく、ほぼ画面全体を移動可能
- 画面端まで動かしてもカメラは自動追尾しない
- マウス中ボタンを押している間だけ、マウス移動とカメラ回転を直接同期
- 射撃判定は現在のクロスヘア位置から行う

### スコープ時

- 右クリック長押しでスコープ
- スコープ照準は中央固定
- マウス移動とカメラ回転を直接同期
- マウスホイールで2.0x〜8.0xズーム

## 射撃 / 着弾

- 左クリックで射撃
- レイキャストで命中判定
- 表示上の弾丸とトレーサーが着弾点へ飛ぶ
- 地面・道路・歩道・建物は壊れない
- 環境への命中時は火花・粉塵エフェクト
- ターゲットへの命中時は破片化して壊れる演出
- ターゲットは一定時間後に再出現

## 移動オブジェクト

### 車

- 複数レーンを走行
- 個体ごとに速度差あり
- 同じレーンの前方車両との距離を見て減速 / 停止
- 速度差があっても車同士が重なりにくい制御

### 歩行者

- 複数の歩道レーンを移動
- 同じレーンの前方歩行者との距離を見て減速 / 停止
- 人同士が重なりにくい制御

## 街

v0.6でさらに拡張しました。

- メイン道路を長く拡張
- 交差道路を複数配置
- 左右のビルを3列構成に拡張
- 手前のビルだけでなく奥側にも高層ビル群を配置
- 前後方向に遠景スカイラインを配置
- ワイド画面でも左右や奥が空白になりにくい構成
- 描画距離とフォグ距離を延長
- 一部の窓に人物ターゲットを配置

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 通常時: クロスヘア移動 / スコープ時: カメラ操作 |
| マウス中ボタン長押し + マウス移動 | 通常時のカメラ旋回 |
| 左クリック | 射撃 |
| 右クリック長押し | スコープ |
| マウスホイール | ズーム倍率変更（2x〜8x） |
| R | リロード |
| Esc | マウスロック解除 |

## 起動方法

GitHub Pagesを有効にしている場合:

```text
https://inowoo.github.io/street-scope/
```

ローカルではリポジトリのルートで以下を実行します。

```bash
python -m http.server 8000
```

その後:

```text
http://localhost:8000/
```
